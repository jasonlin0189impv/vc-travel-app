## 首爾旅遊 App (Seoul Trip App) 專案建置指南

這份指南將協助您在本地端建立一個標準的 React + Vite + Tailwind CSS 專案結構，以便上傳至 GitHub 並進行部署。

## 1. 推薦的專案目錄結構

請依照以下結構建立資料夾與檔案：

```
seoul-trip-2025/              (專案根目錄)
├── public/                   (放置靜態檔案，如 favicon)
├── src/                      (原始碼目錄)
│   ├── App.jsx               <-- 核心！將剛剛寫好的 SeoulTripApp.jsx 內容全部貼到這裡
│   ├── main.jsx              <-- 程式入口點 (下方有程式碼)
│   └── index.css             <-- CSS 設定 (下方有程式碼)
├── .gitignore                <-- Git 忽略清單 (非常重要)
├── index.html                <-- 網頁入口 HTML
├── package.json              <-- 專案設定與套件清單
├── postcss.config.js         <-- Tailwind 設定
├── tailwind.config.js        <-- Tailwind 設定
└── vite.config.js            <-- Vite 建置設定
```

## 2. 關鍵檔案內容範本

請依序建立以下檔案並填入對應內容。

`package.json`

定義專案資訊與需要的套件 (React, Tailwind, Lucide Icons)。

```
{
  "name": "seoul-trip-2025",
  "private": true,
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0",
    "lucide-react": "^0.263.1"
  },
  "devDependencies": {
    "@vitejs/plugin-react": "^4.0.3",
    "autoprefixer": "^10.4.14",
    "postcss": "^8.4.27",
    "tailwindcss": "^3.3.3",
    "vite": "^4.4.5"
  }
}
```

`vite.config.js`

Vite 的設定檔。
```
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

// [https://vitejs.dev/config/](https://vitejs.dev/config/)
export default defineConfig({
  plugins: [react()],
})
```

`tailwind.config.js`

告訴 Tailwind CSS 要去掃描哪些檔案。
```
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

`postcss.config.js`

CSS 處理器的設定。
```
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

`index.html`

網頁的進入點，這裡設定了手機版的視窗控制 (避免縮放)。
```
<!DOCTYPE html>
<html lang="zh-TW">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no" />
    <title>首爾五天四夜之旅</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
```

`src/index.css`

引入 Tailwind CSS 的樣式。
```
@tailwind base;
@tailwind components;
@tailwind utilities;

/* 全局樣式設定，優化手機體驗 */
body {
  background-color: #f8fafc; /* bg-slate-50 */
  overscroll-behavior-y: none; /* 防止下拉重整 */
  -webkit-tap-highlight-color: transparent;
}
```

`src/main.jsx`

React 的啟動點。
```
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

3. 操作步驟

建立資料夾：在您的電腦上建立一個資料夾 `seoul-trip-2025`。

建立檔案：依照上述結構，建立對應的檔案並填入內容。

貼上程式碼：將我們剛剛完成的 SeoulTripApp.jsx 的所有內容，複製並貼上覆蓋到 src/App.jsx 中。

安裝依賴 (如果您有安裝 Node.js)：
打開終端機 (Terminal)，進入資料夾，輸入 npm install。

測試執行：
輸入 npm run dev，瀏覽器打開 http://localhost:5173 應該就能看到 App 了！

上傳 GitHub：
```
git init
git add .
git commit -m "Initial commit: Seoul Trip App"
# 接著關聯您的 GitHub Repository 並 push
```

完成上傳後，推薦使用 Vercel 進行部署，只需連結您的 GitHub 帳號，選擇這個專案，點擊 Deploy 即可自動完成，完全免費且支援 HTTPS。
